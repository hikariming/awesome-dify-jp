# awesome-dify-jp

このプロジェクトのウェブサイトを作成しました。ぜひご覧ください

[useDify](https://usedify.app/)



useDifyは、Difyのインストール、使用方法、チュートリアル、事例を日本語で提供するサードパーティサイトです。公式ドキュメントと比較して、より詳細なインストールガイドを提供し、中国語や英語の優れたDifyチュートリアルや資料を日本語に翻訳することで、日本語ユーザーの利便性を高めています。ここでは、Difyの優れたプロンプト、ワークフローなどをご覧いただけます。

## ディープリサーチワークフロー

[Open-Deep-Research-workflow-on-Dify](https://github.com/AdamPlatin123/Open-Deep-Research-workflow-on-Dify) プロジェクトを翻訳・ローカライズし、ディープリサーチ機能の日本語化を実現しました。このワークフローには以下の特徴があります：

- インテリジェントなトピック解析：Gemini 2.0 Flashモデルを使用した多層的なトピック分解
- ハイブリッド検索エンジン：ローカルナレッジベースとウェブ検索（Wikipedia/Google/Bing API）のサポート
- ダイナミックなリズム制御：2>1モデルカスケードアーキテクチャの採用
- 効率的なレポート生成：Markdown構造化出力のサポート

このワークフローにより、ユーザーは5分以内に万字レベルの構造化研究レポートを生成することができ、特に日本語ユーザーによる深い研究と分析に適しています。

## ワークフロー集

[Awesome-Dify-Workflow](https://github.com/svcvit/Awesome-Dify-Workflow) プロジェクトを翻訳・ローカライズし、以下のような便利なワークフローを日本語で提供しています：

- SEOスラッグ生成
- ドキュメントチャットテンプレート
- 検索マスター
- タイトル作成
- 記事リライト
- テキストからカード生成
- Dify運営一括ツール
- Jina Reader Jinja
- コード翻訳
- その他多数の便利なワークフロー

これらのワークフローは、Dify 0.13.0 以降のバージョンで使用可能で、タスクの並列実行、セッション変数、フォーム、echartレンダリングなどの機能をサポートしています。
